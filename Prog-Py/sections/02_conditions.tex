\subsection{Boolesche Ausdrücke und Operatoren}
\begin{itemize}
    \item \textbf{Walrus-Operator (\texttt{:=})}: Weist einen Wert zu und gibt ihn direkt innerhalb eines Ausdrucks zurück.
    \item \textbf{Ternärer Operator}: Kompakte Syntax für einfache, einzeilige bedingte Zuweisungen.
    \item \textbf{\texttt{==} vs \texttt{is}}:
    \begin{itemize}
        \item \texttt{==} prüft auf reine Wertgleichheit; 
        \item \texttt{is} prüft Objektidentität im Speicher (ideal für \texttt{None}-Prüfung).
    \end{itemize} 
    \item \textbf{\texttt{in}-Operator}: Prüft Vorhandensein in Objekten via \texttt{\_\_contains\_\_()} (Nur für Iterables nutzbar: Listen, Strings, Dicts).
\end{itemize}

\subsection{Ausnahmebehandlung (Exception Handling)}
\begin{itemize}
    \item \textbf{LBYL (Look Before You Leap)}: Defensiver Stil, prüft explizit Bedingungen vor dem Aufruf. Anfällig für "Race Conditions" (Zustand ändert sich zw. Prüfung und Aktion).
    \item \textbf{EAFP (Easier to Ask Forgiveness...)}: Pythonischer Ansatz. Geht von Erfolg aus und nutzt \texttt{try/except}. Meist sauberer und robuster in Multi-Threading.
    \item \textbf{Exceptions fangen}: Immer spezifische Exceptions fangen, keine generischen. \texttt{as}-Keyword zur Inspektion des Exception-Objekts verwenden.
    \item \textbf{Ablaufsteuerung}:
    \begin{itemize}
        \item \texttt{else}: Läuft nur, wenn der \texttt{try}-Block fehlerfrei erfolgreich war.
        \item \texttt{finally}: Läuft immer (z.B. für Dateifreigabe), ungeachtet dessen, ob eine Exception auftrat.
    \end{itemize}
\end{itemize}
